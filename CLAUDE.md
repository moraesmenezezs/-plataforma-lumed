## Sobre o Projeto

Este e o projeto da **Plataforma LuMED** (https://plataformalumed.site), uma plataforma educacional para estudantes de ENEM e vestibulares.

A documentacao completa de tudo que foi construido esta na pasta `O PROJETO - MARIA/LEIA-ME.md`. Leia esse arquivo para entender toda a arquitetura antes de fazer alteracoes.

## Stack

- Frontend: HTML/CSS/JS puro (sem framework)
- Auth: Supabase (js/auth.js)
- Banco de dados: Firebase Firestore (aulas ao vivo/gravadas)
- Hosting: Vercel
- Videos: Google Meet + Drive + Apps Script
- Design: Tema roxo/rosa, fonte Plus Jakarta Sans, Bootstrap Icons
